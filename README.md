# WhatsApp Chat Brain

Local-first Windows app that turns a WhatsApp chat export full of links into federated
Obsidian "brains" you can query by text or local voice (RAG over RAG, BYOK or local LLMs).

Status: **specification only, development not started.**

- `docs/APP_SPEC.md`: what the app must do
- `docs/BUILD_PROTOCOL.md`: how Claude builds it (models, 30-minute sessions, reports)
- `docs/PROGRESS.md`: milestones, tasks and session log
- `docs/GOAL_PROMPTS.md`: setup and the `/goal` prompt that runs each build session
